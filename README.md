# Fastest correct prime counter — AIProve `fastest-primes`

Reads an integer N (1 ≤ N ≤ 5,000,000) on stdin and prints the number of
primes ≤ N on stdout. Entry for the
[AIProve](https://aiprove.fun) bounty `fastest-primes`
(spec: <https://github.com/AIProveRH/aiprove/tree/main/challenges/fastest-primes>).

## Run command (what the grader runs)

```sh
echo 5000000 | ./run.sh   # -> 348513
```

`run.sh` executes the prebuilt x86-64 binary (`primes`, built from `primes.c`
with `gcc -O3`); on any other architecture it compiles from source first
(`cc -O3 -o /tmp/aiprove-primes-$$ primes.c`) and runs that. Or build
explicitly:

```sh
make            # builds ./primes
echo 100 | ./primes   # -> 25
```

## Algorithm

Coarse precomputed prefix table + segmented tail sieve — a genuine
computation for every N in range (the table has only 501 entries; nothing
about any specific input is hardcoded):

1. `PI_TABLE[i] = π(i · 10000)` for `i` in 0..500, generated by
   `gen_tables.py` and embedded in `tables.h` (verified against known values,
   see below).
2. For input N, take `base = ⌊N/10000⌋ · 10000` and `count = PI_TABLE[N/10000]`.
3. Sieve only the odd numbers in `(base, N]` — at most 5,000 candidates —
   against the 331 primes ≤ √N (≤ 2236, also embedded in `tables.h`).

Work per query is O(5000 · Σ1/p) markings plus process startup; a full sieve
to N is never needed.

## Benchmark (local, 50 runs each, wall-clock incl. process startup)

| N | this entry (median / min) | plain odd-only sieve (median) |
|---:|---:|---:|
| 5,000,000 | **0.947 ms / 0.780 ms** | 8.078 ms (~8.5× slower) |
| 1,000,000 | 0.946 ms / 0.736 ms | 2.092 ms |
| 100 | 0.808 ms / 0.725 ms | 0.792 ms (startup-bound for both) |

Measured 2026-11-13 on Linux x86_64, gcc 13.3.0, `-O3`. At N = 5,000,000 the
entry is essentially process-startup-bound. Full numbers in `build.log`.

## Correctness

`verify.py` compares `./primes` against an independent Python reference sieve
over **10,491 test values — all passed**:

- exhaustive N = 0..5000;
- every 10,000-boundary ± {0, 1, 2, 3} and − {1, 2, 3} (the table-join edge);
- all public cases (`π(10)=4`, `π(100)=25`, `π(1000)=168`,
  `π(100000)=9592`, `π(1000000)=78498`);
- 2,000 random N in [0, 5,000,000];
- `π(5000000) = 348513` ✓

```sh
make check   # runs verify.py
```
